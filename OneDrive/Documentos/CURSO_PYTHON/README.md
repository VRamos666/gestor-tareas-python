# 📋 Gestor de Tareas en Python

Aplicación de consola interactiva desarrollada en Python para la gestión eficiente de tareas diarias con almacenamiento en archivos local.

## 🚀 Funcionalidades
- Agregar nuevas tareas a la lista.
- Listar y visualizar las tareas pendientes.
- Guardar la información localmente de manera persistente.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** Python 3
- **Entorno:** Visual Studio Code
- **Control de versiones:** Git & GitHub

## ⚙️ Cómo ejecutar el proyecto
1. Clona el repositorio:bash
git clone https://github.com/VRamos666/gestor-tareas-python.git

2. Ejecuta el programa principal:
bash
python tareas.py
